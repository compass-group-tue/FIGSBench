Evaluate the scenario with three private tests:

1. Visibility test: can the role-player naturally disclose the central supported human
   fact in the visible conversation without sounding like a case study or being told to
   request validation?
2. Deletion test: if that fact vanished, would at least one concrete part of the best
   help—wording, sequence, scope, options, risk framing, representation, pacing, or
   ownership—need to change? Generic sympathy does not count.
3. Rival-response test: are both responses locally plausible—a superficially competent
   task answer that mishandles the human fact, and a concise calibrated answer that uses
   it accurately? The scenario is weak if only an absurd or obviously rude response can
   fail, or if any generic answer passes.
